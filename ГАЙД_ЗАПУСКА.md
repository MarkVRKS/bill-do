# Как запустить Счетовод

## 1. PostgreSQL (Docker)

```bash
docker run -d --name schetovod-db \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=schetovod \
  -p 5434:5432 \
  postgres:16-alpine
```

Если контейнер уже есть:
```bash
docker start schetovod-db
```

## 2. Бэкенд

```bash
cd server
npm install          # если не установлено
npm run db:push      # создать таблицы
npm run dev          # запуск на http://localhost:3000
```

## 3. Фронтенд (отдельная вкладка)

```bash
cd client
npm install          # если не установлено
npm run dev          # запуск на http://localhost:5173
```

## 4. Десктоп (Electron)

```bash
cd desktop
npm install          # если не установлено
npx electron .       # запуск приложения
```

## 5. Seed тарифов

```bash
curl -X POST http://localhost:3000/api/billing/seed-plans
```

## Порты

| Сервис | Порт |
|--------|------|
| PostgreSQL | 5434 |

## Если что-то не запускается

1. `docker ps` — проверь что PostgreSQL работает
2. `curl http://localhost:3000/api/health` — проверь бэкенд
3. `curl http://localhost:5173` — проверь фронтенд
4. В логах бэкенда (`/tmp/server.log`) будет ошибка если БД недоступна
