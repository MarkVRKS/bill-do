# Бухкрафт

Десктопное приложение для выставления счетов на оплату и актов оказанных услуг. Автономное — все данные хранятся локально на вашем компьютере.

## Что это

Бухкрафт — это сервис для предпринимателей и бухгалтеров, который позволяет за минуту создать профессиональный счёт на оплату или акт оказанных услуг. Приложение работает полностью офлайн, данные не покидают ваш компьютер.

## Возможности

### Счета на оплату
- Создание счетов с предпросмотром в реальном времени
- Автоматический расчёт НДС (0%, 10%, 20%, 22%)
- Сумма прописью (автоматически)
- Несколько оснований (договоров) в одном счёте
- Выбор покупателя из базы
- Экспорт в Excel (.xlsx)
- Экспорт в PDF
- Печать через системный диалог

### Акты оказанных услуг
- Автоматическая генерация акта на основе данных счёта
- Экспорт в Excel (.xlsx)
- Экспорт в PDF
- Печать через системный диалог

### Журнал документов
- Все счета и акты в одном месте
- Фильтры по дате, статусу, поиску
- Быстрый доступ к скачиванию и печати
- Просмотр деталей счёта

### Организации
- Поддержка нескольких организаций
- Переключение между организациями
- Хранение реквизитов: ИНН, КПП, ОГРН, адрес, банковские реквизиты
- Указание руководителя и бухгалтера

### Покупатели
- База покупателей с реквизитами
- Несколько оснований (договоров) на покупателя
- Быстрое добавление при создании счёта

### Настройки
- Настройка пути загрузок (куда сохраняются файлы)
- Выбор папки через системный диалог
- Конфиденциальность: все данные локально

## Технологии

- **Electron** — десктопное приложение
- **React** — пользовательский интерфейс
- **TypeScript** — типизация
- **Fastify** — встроенный сервер
- **SQLite (sql.js)** — локальная база данных
- **ExcelJS** — генерация Excel-файлов
- **Playwright** — генерация PDF

## Установка

### Windows
1. Скачайте `Бухкрафт Setup X.X.X.exe`
2. Запустите установщик
3. Следуйте инструкциям мастера установки
4. Приложение появится в меню Пуск и на рабочем столе

### Удаление
- Через «Установка и удаление программ» в Windows
- Или через «Программы и компоненты» в Панели управления

## Сборка из исходников

```bash
# Установка зависимостей
cd desktop
npm install

# Запуск в режиме разработки
npm start

# Сборка Windows-установщика
npm run build:win

# Сборка macOS
npm run build

# Сборка Linux
npm run build:linux
```

## Форматы файлов

### Названия файлов
Файлы сохраняются с полными названиями:
- `Счет_на_оплату_№107_ООО_Компания_Июль_2026.xlsx`
- `Счет_на_оплату_№107_ООО_Компания_Июль_2026.pdf`
- `Акт_оказанных_услуг_№107_ООО_Компания_Июль_2026.xlsx`
- `Акт_оказанных_услуг_№107_ООО_Компания_Июль_2026.pdf`

### Содержимое
- **Excel** — форматированный документ с реквизитами, таблицей позиций, итогами и подписями
- **PDF** — готовый к печати документ формата A4

## Безопасность

- Все данные хранятся локально в SQLite
- Никакие данные не передаются на внешние серверы
- Нет телеметрии и аналитики
- Полная конфиденциальность
